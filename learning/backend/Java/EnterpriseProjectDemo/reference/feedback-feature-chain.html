注解速查

注解层含义
@RestControllerController方法返回值直接序列化为 JSON 响应
@PutMapping/@GetMappingController把 HTTP 方法+路径绑到 Java 方法
@AdminAuthController 类自定义注解：仅管理员可访问
@TransactionalService 方法方法内 DB 操作同一事务，异常回滚；readOnly=true 是只读优化提示
@TableNameEntityMyBatis-Plus：类↔表映射
@TableField(updateStrategy=ALWAYS)Entity 字段即使字段为 null 也写进 UPDATE（用于把列清空）
@RequiredArgsConstructor类Lombok：为 final 字段生成构造器，配合构造器注入

表字段速记

列含义
ORG_CODE / USER_ID组织隔离键 + 提交人（幂等键的一半）
SESSION_ID / RUN_ID / MESSAGE_ID定位三元组：哪次会话的哪次运行的哪条回答
FEEDBACK / PROBLEM_TYPES / NOTE评价本体：good/bad · 逗号串问题类型 · 备注
QUESTION_TEXT / ANSWER_TEXT / QUESTION_SUMMARY快照：评价时刻的问答内容
ASSOCIATION_STATUS原会话/消息是否还能关联上
FIRST_FEEDBACK_TIME / SNAPSHOT_TIME首次评价时间（查询过滤轴）/ 快照时间
