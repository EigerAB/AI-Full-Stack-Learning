### 1、Java Lambda 需匹配函数式接口

**Java Lambda 需要匹配一个“函数式接口”类型**，也就是只有一个抽象方法的接口。这个接口规定参数和返回值的类型。

先自己定义一个简单接口：

```java
@FunctionalInterface
interface NameChecker {
    boolean check(String name);
}
```

它只有一个没有方法体的方法：

```java
boolean check(String name);
```

这种方法叫**抽象方法**。它规定：

- 方法接收一个 `String`。
- 方法必须返回一个 `boolean`。
- 具体如何判断，由实现者决定。

因为这个接口只有一个抽象方法，所以可以用 Lambda 提供实现：
```java
NameChecker checker = name -> name.startsWith("Java");
```

“需要匹配”就是说 Lambda 的参数和返回结果必须符合接口的要求。

但是我看到你的代码里.filter、.map等的这些方法没有匹配抽象方法啊？

```java
List<String> names = List.of("Java入门", "Python入门", "Java实战");
List<String> result = names.stream()
        .filter(name -> name.startsWith("Java"))
        .map(name -> name + "课程")
        .toList();
System.out.println(result);
```

以你的代码为例：

```
.filter(name -> name.startsWith("Java"))
```

在 VS Code 中可以这样查：

1. **悬停在 `filter` 上**，查看方法声明，会看到类似：
    
    ```
    Stream<T> filter(Predicate<? super T> predicate);
    ```
    
    暂时忽略 `? super T`，先抓住：参数类型是 **`Predicate`**。
    
2. 在 `filter` 上按 **F12** 跳转到定义，再对参数类型 **`Predicate`** 跳转到定义。
    
3. 在 `Predicate` 接口中找到：
    
    ```java
    boolean test(T t);
    ```
    
    它没有方法体，以分号结尾。接口中这种方法默认就是 `public abstract`，所以源码可以省略这两个关键字。

### 3、List初始化的方法

需先学习集合篇

|写法|增删元素|`set` 替换元素|
|---|---|---|
|`new ArrayList<>()`|可以|可以，索引必须已存在|
|`List.of(...)`|不可以|不可以|
|`Arrays.asList(...)`|不可以|可以|
|`new ArrayList<>(已有集合)`|可以|可以|
|`stream.toList()`|不可以|不可以|
最后注意一个与泛型有关的坑：**`int[]` 不能通过 `Arrays.asList` 自动变成整数列表。**

```
int[] numbers = {1, 2, 3};

List<int[]> wrong = Arrays.asList(numbers);
System.out.println(wrong.size()); // 1，整个数组被当作一个元素
```

应当这样转换：

```
List<Integer> numbersList = Arrays.stream(numbers)
        .boxed()
        .toList();
```

`boxed()` 把流中的 `int` 转成 `Integer`。

平时可以先记三种：**空的可修改列表用 `new ArrayList<>()`，固定内容用 `List.of(...)`，对象数组转可修改列表用 `new ArrayList<>(Arrays.asList(array))`。**
