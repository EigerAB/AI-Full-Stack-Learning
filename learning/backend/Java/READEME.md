## 1. 学习目标与主线

建立完整的 Java 后端知识体系，既能理解和扩展芋道 ruoyi-vue-pro，也能脱离该项目独立设计、开发、测试和排查 Java 后端服务。

学习主线：

**现代 Java 工程基础 → Spring Boot 后端开发 → 数据与安全 → 并发与可靠性 → 微服务 → AI 平台实战。**

以 Spring 生态为主线，用独立练习掌握通用能力，再通过项目代码验证。项目现有实现是分析案例，需要理解其约束和取舍，不能视为唯一正确答案。

### 2.2 课程技术安排

- 项目练习使用 **Java 17 + Spring Boot 3.5.x**；芋道当前为 3.5.15，第三章独立示例固定为已验证的 3.5.9，两者分别管理依赖。
- 补充 Java 21/25 的代表性特性，后期学习 Spring Boot 4 的迁移差异。Java 21+ 的练习需使用独立环境，不直接加入 Java 17 项目。
- 数据库以 **SQL + MySQL** 为主线，对照芋道 SQL、DO 和 Mapper。Flyway 作为独立练习的版本化迁移工具补充，不描述成芋道默认启动机制。
- 持久层重点学习 **MyBatis/MyBatis-Plus**；JPA/Hibernate 作为选修，理解另一类持久化方案。
- 优先掌握一个工具及其背后的问题，再比较替代方案，避免同时学习大量功能重叠的框架。
- 消息队列按基础概念、RabbitMQ 实践和 Kafka 场景对比学习；芋道有相关 Starter，具体启用情况以模块配置为准。
- 微服务、gRPC 与 Protobuf 保留为通用进阶专题，通过独立练习学习，不假定当前芋道主应用使用这些架构。

### 2.3 跳过与保留

不安排 JSP、Struts、EJB、传统 XML 配置式开发等作为主线课程，也不从手工搭建传统 SSM 项目开始。

“Java Web”不是被淘汰的技术名称，Java EE 也不能整体等同于过时技术。HTTP、Servlet 请求链、Filter、事务等基础仍需学习；Jakarta EE 及 Servlet 规范仍在发展。学习这些概念不要求重走旧式页面开发路线。

## 4. 分章目录与验收目标

### 01 Java 后端工程入门

- JDK、JRE、JVM 的关系，源码编译与运行过程。
- Java 项目目录、包、classpath、JAR 与应用启动入口。
- Maven 生命周期、依赖作用域、传递依赖、依赖冲突。
- Parent、BOM、dependencyManagement 与多模块构建。
- IDE 断点调试、调用栈与异常定位。
- 配置文件、环境变量、日志与基本构建命令。

**验收：**能创建、调试、打包并运行一个 Java 服务，能定位基本依赖冲突。

### 02 面向后端开发的 JavaSE 补强

- 泛型、常用集合、集合选择与复杂度意识。
- `equals`、`hashCode` 与对象相等性。
- 异常体系、业务异常与异常传播。
- Lambda、Stream、Optional 的使用边界。
- 注解、反射及其在框架中的用途。
- 日期时间、时区、金额与 BigDecimal。
- I/O、try-with-resources 与资源关闭。
- 现代 Java 语法：record、switch 表达式等；区分各特性的 JDK 要求。

**验收：**能读懂常见业务代码，并正确处理集合、异常、金额、时间和资源。

### 03 Spring 核心思想

- Spring Framework、Spring Boot、Spring MVC 的关系。
- IoC、DI 与构造器注入。
- Bean 注册、组件扫描、配置类与条件装配。
- Bean 生命周期、作用域与单例对象的线程安全。
- AOP、动态代理与横切逻辑。
- 代理调用和对象内部调用的区别，为事务学习做准备。

**验收：**能解释对象由谁创建、依赖如何注入，以及代理何时生效。

### 04 Spring Boot 与 REST API

- Starter、自动配置、配置绑定与 Profile。
- Controller、请求映射与参数绑定。
- DTO、Jackson 序列化与反序列化。
- Bean Validation 参数校验。
- REST API 设计、状态码、分页与错误响应。
- 全局异常处理与统一响应的适用边界。
- springdoc-openapi 与接口文档。

**验收：**独立实现一个包含参数校验、错误处理、接口文档和基本行为验证的 API。

### 05 Web 请求处理原理

- HTTP 请求、响应、Header、Cookie、Session 的必要复习。
- Servlet 容器和 DispatcherServlet。
- 请求进入应用后的处理链。
- Filter、Interceptor、AOP 的执行位置与职责区别。
- CORS 与浏览器跨域行为。
- 文件上传、下载与流处理。

**验收：**能跟踪请求经过的处理链，定位跨域、参数绑定和文件传输问题。

### 06 关系数据库与 SQL

- 业务表设计、主外键、唯一约束、非空约束与关联关系。
- 查询、关联、聚合、子查询和分页。
- 索引原理、索引选择与执行计划。
- ACID、隔离级别、MVCC、锁与死锁。
- 并发更新、唯一性竞争和慢查询分析。
- 芋道 MySQL 初始化脚本、业务表与数据约束的对应关系。

**验收：**能设计业务表、编写查询，并解释慢查询和并发更新问题。

### 07 MyBatis、MyBatis-Plus 与事务

- JDBC、DataSource 与连接池。
- MyBatis 的 Mapper、参数绑定、结果映射与动态 SQL。
- MyBatis-Plus 的 CRUD、条件构造、分页与批量操作。
- 乐观锁、逻辑删除和自定义 SQL 的边界。

- 自调用、异常被捕获、异步执行等事务失效或不符合预期的场景。

**验收：**完成一个有迁移脚本、事务和并发保护的业务模块，并验证失败时的数据状态。

### 08 业务建模与代码设计

- Controller、Service、Mapper 的职责划分。
- DTO、VO、Entity 的用途与转换。

## 6. 学习方式与练习主线

### 6.1 每节课的固定结构

1. 要解决的问题与使用场景。
2. 核心概念，以及与前端/FastAPI 的对照。
3. 可以独立运行的最小代码。

5. 独立练习。
6. 验收问题、常见错误与学习记录。

### 6.2 独立练习项目

维护一个“小型资源管理服务”，逐步增加以下能力：

1. REST API、校验和错误处理。
2. 数据库、分类、分页、迁移和事务。
3. 用户登录、角色和数据权限。
4. 测试、缓存和异步任务。
5. 外部调用、文件存储和流式响应。
6. 跨服务调用、可靠任务、部署与观测。

先通过独立练习理解通用能力，再阅读目标项目；避免一开始被平台集成和历史实现细节淹没。

### 6.3 FastAPI 对照入口

| 已有知识 | Java 学习入口 | 需要区分的地方 |
| --- | --- | --- |
| 路由、APIRouter | Controller、请求映射与模块组织 | 模块边界不只等于路由分组 |
| Pydantic 模型 | DTO + Jackson + Bean Validation | 数据表达、序列化和校验分属不同职责 |
| `Depends` | Spring DI | 注入机制、对象生命周期和作用域不同 |
| middleware | Filter、Interceptor | 执行位置和访问上下文不同 |
| exception handler | `@RestControllerAdvice` | 需理解异常发生位置及处理覆盖范围 |
| Uvicorn/ASGI | Servlet 容器与 WebFlux 运行模型 | 两套运行模型不能直接等同 |
| `async/await` | 线程池、CompletableFuture、Reactor | 异步不自动等于非阻塞或更高性能 |
