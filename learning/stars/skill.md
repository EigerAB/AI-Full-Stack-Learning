## 笔记相关

### kepano/obsidian-skills
 
https://github.com/kepano/obsidian-skills
适合你想让 Codex 正确读写 Obsidian 笔记、维护链接、属性、Canvas 的场景。
包含：
- obsidian-markdown：创建和编辑 Obsidian Markdown
- obsidian-cli：通过 CLI 读取、搜索和管理笔记
- obsidian-bases：创建类似数据库的笔记视图
- json-canvas：创建画布、思维导图
- defuddle：网页转干净 Markdown
- knap：根据模板批量生成 Markdown

### book-to-skill
 
[https://github.com/virgiliojr94/book-to-skill](https://github.com/virgiliojr94/book-to-skill)

它可以把一本技术书、笔记方法论或一组文档，转换成一个 Agent Skill。生成的结构包括：

```
SKILL.md          # 核心方法论和章节索引
chapters/         # 分章节知识
glossary.md       # 术语表
patterns.md       # 方法、模式、算法
cheatsheet.md     # 快速决策表
```

它的目标不是让 AI 总结一本书，而是让 AI真正“学会”这本书中的框架、判断规则和反模式，并在需要时按章节读取。
