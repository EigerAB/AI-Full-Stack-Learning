# 学习使命

## 目标

上手维护开发 SmartSquare 后端项目。能够独立读懂代码、完成功能修改和 bug 修复，并理解项目的架构设计决策以便做出符合规范的新改动。

## 当前水平

- Java 基础扎实，Spring Boot/Security/Cloud 用得不多，需要从 Spring 基础讲起
- 微服务、AI 协议集成经验较少

## 优先方向（按顺序）

1. **微服务架构**：多模块拆分、Nacos 注册发现、Gateway 路由、OpenFeign 调用、模块依赖方向
2. **认证授权体系**：JWT 机制、JADP 集成、网关鉴权、角色注解、OAuth2/OIDC 第三方登录

## 后续可扩展方向

- AI 对话与协议（AG-UI / A2A / SSE / 意图识别 gRPC）
- 智能编码与 MCP（WebSocket / JSON-RPC / 远程沙箱 / CLI Provider）
- 数据持久化（MyBatis-Plus / DM8 达梦 / Flyway 迁移）
- 可观测与计费（SLS / DB 双数据源）

## 学习原则

- 每节课都锚定到这个项目的真实代码，不学脱离项目的抽象理论
- 先建立整体认知地图，再逐层深入
- 优先理解「为什么这样设计」，而非只记「用了什么技术」
