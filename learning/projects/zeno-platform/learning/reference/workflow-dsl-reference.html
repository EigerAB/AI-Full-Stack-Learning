Workflow DSL 速查

ZenFlux Agent · 读代码优先

一张图的最小结构

{
  "version": "1.0",
  "meta": {"skeleton": "default_v1"},
  "nodes": [
    {"id": "begin_1", "type": "Begin", "data": {"mode": "conversational"}},
    {"id": "agent_1", "type": "Agent", "data": {"llm_id": null, "max_rounds": 5}}
  ],
  "edges": [
    {"source": "begin_1", "target": "agent_1"}
  ]
}

常见节点类型

  • Begin：入口，启动工作流
  • Agent：跑 LLM / 执行提示词
  • Reply：输出最终回复
  • Switch：分支判断
  • Categorize：分类
  • ToolCall：调用工具
  • Loop：循环容器
  • LoopBreak / LoopContinue：循环控制
  • SubWorkflow：嵌套子工作流
  • Question：挂起式提问

最关键的入口

  • core/agent/workflow_dsl.py：DSL 定义、校验、默认骨架
  • core/agent/workflow_node_registry.py：节点注册表
  • core/agent/workflow_node_executors.py：每种节点的执行闭包
  • core/agent/agent_workflow_debug.py：真正调试/运行节点逻辑

排障口诀

  1. 先验证图合法：validate_workflow_dsl()
  2. 再看节点类型：有没有 Agent / Switch / Loop
  3. 再看边和变量：节点输出是否写回变量池
  4. 最后看节点实现：执行器是不是返回了正确的结果
