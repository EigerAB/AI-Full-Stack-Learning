SubAgent / Team runtime

一张图：问题从哪儿来

父级 AgentLoop
  └─ subagent/tool call
      └─ SubagentRunner.run()
          ├─ _create_child_context()
          │   ├─ 复制 ExecutionContext
          │   ├─ 过滤工具白名单 / 去掉 agent 工具
          │   └─ 生成 child_agent_id
          ├─ AgentLoop(child_context)
          └─ 回传最终文本作为工具结果

最关键的文件

  • core/agent/execution/subagent/runner.py：子代理运行器
  • core/agent/execution/subagent/definition.py：AgentDefinition
  • core/agent/execution/subagent/registry.py：注册中心
  • core/agent/execution/team/runtime.py：team 入口
  • core/agent/execution/team/coordinator.py：协调器

排障入口

  • 子代理工具结果不回传：看 parent_tool_use_id、subagent_id。
  • 子代理工具被错误继承：看 definition.tools is None 与白名单过滤逻辑。
  • 同一批事件被混进同一条流：看 broadcaster_agent_id。
  • team 成员不生效：看 workers 配置、agent_id、alias 去重。

一句话结论

多智能体的核心不是“多轮模型”，而是“多套上下文 + 多套身份 + 多套事件归属”。只要 identity 和 context 边界没搞清，排障就会被表象迷住。
